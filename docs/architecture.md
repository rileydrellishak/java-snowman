# Architecture

| Layer             | Recommendation                     | Why                                                              |
| ----------------- | ---------------------------------- | ---------------------------------------------------------------- |
| Frontend          | **React + Vite**                   | I already know this, so the Java backend is the learning focus   |
| Frontend language | **JavaScript**                     | Same reason; don't add TypeScript simultaneously                 |
| Backend           | **Java + Spring Boot**             | The most useful Java web framework to learn for SWE jobs         |
| Build tool        | **Maven**                          | Very common in Java/Spring projects and a nice contrast with npm |
| API               | **Spring Web / REST**              | Familiar Flask-style request → controller → service flow         |
| Testing           | **JUnit 5**                        | The standard Java testing framework                              |
| Persistence       | **Browser localStorage initially** | No database needed for the game itself                           |
| Backend database  | **None initially**                 | Keep the API focused on practicing Java                          |
| Dev environment   | VS Code or IntelliJ                | Either is fine; IntelliJ is especially nice for Java             |
